# dh-plugin-template

Inherit `../CLAUDE.md` and the vault standards. This is a public GitHub template and must remain a small, working conformance reference.

- Keep the example executable and tested; do not turn the template into a real vendor integration.
- Rename repository ID, entry point, Python package, manifest, runtime components, and tests together.
- Public examples use logical names and `.invalid` addresses only.
- Mutation remains disabled in the reference implementation.
- Changes must preserve strict typing, manifest drift checks, CI, and public-surface validation.
